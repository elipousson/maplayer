# Package index

## Location layers for ggplot2 maps

- [`layer_location_data()`](https://elipousson.github.io/maplayer/reference/layer_location_data.md)
  : Layer location data into a ggplot2 map
- [`layer_labelled()`](https://elipousson.github.io/maplayer/reference/layer_labelled.md)
  : Label simple feature objects in a location
- [`layer_location()`](https://elipousson.github.io/maplayer/reference/layer_location.md)
  : Layer a location border into a ggplot2 map
- [`layer_location_context()`](https://elipousson.github.io/maplayer/reference/layer_location_context.md)
  : Create a layer showing a location and related context

## Additional layers for sf objects

- [`layer_arrow()`](https://elipousson.github.io/maplayer/reference/layer_arrow.md)
  : Create a layer with an arrow or segment from and to specified
  locations
- [`layer_count()`](https://elipousson.github.io/maplayer/reference/layer_count.md)
  : Layer for counting occurrences of data in spatial relation a
  location or other sf object
- [`layer_frame()`](https://elipousson.github.io/maplayer/reference/layer_frame.md)
  [`make_frame()`](https://elipousson.github.io/maplayer/reference/layer_frame.md)
  : Create a frame layer around a simple feature object
- [`layer_grouped()`](https://elipousson.github.io/maplayer/reference/layer_grouped.md)
  : Make group layers
- [`layer_icon()`](https://elipousson.github.io/maplayer/reference/layer_icon.md)
  [`geom_sf_icon()`](https://elipousson.github.io/maplayer/reference/layer_icon.md)
  : Use ggsvg to add a layer with icons at feature locations
- [`layer_image_path()`](https://elipousson.github.io/maplayer/reference/layer_image_path.md)
  : Use ggpath to create a layer with images at locations
- [`layer_mapbox()`](https://elipousson.github.io/maplayer/reference/layer_mapbox.md)
  : Use mapboxapi to make a Mapbox static map layer
- [`layer_marked()`](https://elipousson.github.io/maplayer/reference/layer_marked.md)
  : Use ggforce to create an annotation layer using simple feature data
- [`layer_markers()`](https://elipousson.github.io/maplayer/reference/layer_markers.md)
  [`layer_numbers()`](https://elipousson.github.io/maplayer/reference/layer_markers.md)
  [`make_markers()`](https://elipousson.github.io/maplayer/reference/layer_markers.md)
  : Create a ggplot2 layer with map markers or numbered markers
- [`layer_mask()`](https://elipousson.github.io/maplayer/reference/layer_mask.md)
  [`set_mask()`](https://elipousson.github.io/maplayer/reference/layer_mask.md)
  : Create a mask layer based on a simple feature object
- [`layer_neatline()`](https://elipousson.github.io/maplayer/reference/layer_neatline.md)
  [`theme_grid()`](https://elipousson.github.io/maplayer/reference/layer_neatline.md)
  [`theme_sf_axis()`](https://elipousson.github.io/maplayer/reference/layer_neatline.md)
  [`set_neatline()`](https://elipousson.github.io/maplayer/reference/layer_neatline.md)
  : Set map limits to a bounding box with a buffer and set aspect ratio
- [`layer_repel()`](https://elipousson.github.io/maplayer/reference/layer_repel.md)
  [`geom_sf_label_repel()`](https://elipousson.github.io/maplayer/reference/layer_repel.md)
  [`geom_sf_text_repel()`](https://elipousson.github.io/maplayer/reference/layer_repel.md)
  : Use ggrepel to create text annotations based on simple features
- [`layer_scaled()`](https://elipousson.github.io/maplayer/reference/layer_scaled.md)
  : Create a ggplot2 layer scaled to a paper and orientation for a
  location
